# Smart Urban Noise Monitoring System - Backend API

RESTful API backend powered by Express.js, Node.js, MongoDB, Mongoose, and JWT.

## Setup & Running
```powershell
# 1. Install dependencies
npm install

# 2. Configure environment
Copy-Item .env.example .env

# 3. Start server
npm start

# Development mode with watch:
npm run dev

# Seed demo data standalone:
npm run seed
```
