# Smart Urban Noise Monitoring System - Frontend Client

Responsive React SPA built with Vite, Tailwind CSS, React Router v6, and Lucide React.
Designs replicate the Figma specification for Citizen and Municipal Staff portals.

## Setup & Running
```powershell
# 1. Install dependencies
npm install

# 2. Start Vite dev server
npm run dev

# 3. Build for production
npm run build
```

Application will run at `http://localhost:5173`.
